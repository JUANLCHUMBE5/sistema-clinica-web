# Sistema Web de Gestión de Clínica

Proyecto académico de sistema web para la gestión de una clínica, desarrollado con fines educativos.

## Funcionalidades
- Gestión de pacientes
- Gestión de citas médicas
- Gestión de médicos
- Operaciones CRUD
- Autenticación básica

## Tecnologías
- JavaScript
- HTML / CSS
- Base de datos SQL

## Rol en el proyecto
Desarrollo de funcionalidades y conexión con base de datos.

## Nota
Proyecto académico. No contiene información real de pacientes.
